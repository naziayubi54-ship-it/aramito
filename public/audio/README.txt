Real nature recordings — drop them here (no code change needed)
================================================================

File names (any ONE of: .mp3 .ogg .m4a .wav):

  forest     -> جنگل انبوه
  fire       -> هیزم آتش و شومینه
  cafe       -> زمزمه کافه
  crickets   -> جیرجیرک شب

Tips
- 30–120 seconds is enough. The app loops each file with an equal-power
  crossfade, so the loop point is inaudible even if start/end don't match.
- Stereo, 128 kbps mp3 (or ogg) keeps the app small.
- Pick CC0 / royalty-free files whose licence allows use inside an app:
    https://freesound.org  (filter: License = Creative Commons 0)
    https://bigsoundbank.com  (CC0)
    https://mixkit.co/free-sound-effects/  (e.g. /forest/, search "fireplace", "cafe", "crickets")
