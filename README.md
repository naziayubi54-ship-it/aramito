# آرامیتو (Aramito) 🌿
### اپلیکیشن موبایل آرامش، تنفس و مدیتیشن بر پایه شواهد علمی (Liquid Glass)

«آرامیتو» یک اپلیکیشن کاملاً فارسی، آفلاین و بدون نیاز به اینترنت برای آرام‌سازی سیستم عصبی، تنظیم ضربان قلب و عصب واگ، بهبود خواب و ارتقای تمرکز بر مبنای پژوهش‌های دانشگاه‌های استنفورد، هاروارد و راتگرز است.

---

## ویژگی‌های اصلی
۱. **طراحی ترند ۲۰۲۶ (Liquid Glass):**
   - کارت‌های شیشه‌ای مات با بلور عمیق (Frosted Glass)
   - گرادیان‌های آرورا و هاله نورانی زنده
   - پالت رنگی روز (کرم‌مه، سبز مریمی، آبی مه، اسطوخودوس) و پالت شب (سرمه‌ای عمیق، نیلی، درخشش ماه)
   - پشتیبانی از تم روشن، تیره و خودکار (تغییر خودکار بعد از غروب آفتاب)
   - نوار پایین قرصی با دکمهٔ گرد موسیقی آرامش، منوی کناری و مینی‌پلیر شناور

۲. **تمرینات تنفسی علمی (۸ سبک با انیمیشن‌های اختصاصی):**
   - تنفس جعبه‌ای ۴-۴-۴-۴ (انیمیشن کادر مربعی)
   - تنفس ۴-۷-۸ (کره نورانی منبسط‌شونده برای خواب)
   - تنفس رزونانس/همدوس ۵.۵ تنفس در دقیقه برای اوج تنوع ضربان قلب (HRV)
   - آه فیزیولوژیک (دو دم + بازدم طولانی - مطالعه استنفورد، Cell Reports Medicine 2023)
   - تنفس دیافراگمی، نادی شودانا (سوراخ متناوب بینی)، بازدم طولانی خواب و تمرکز ۴-۴
   - فیدبک لمسی (Haptic) و راهنمای صوتی ناقوس تبتی در تغییر فازها

۳. **صداساز و میکسر طبیعت (Web Audio API):**
   - ۱۴ کانال صوتی با امکان تنظیم ولوم مستقل و میکس همزمان
   - شبیه‌سازی رویه‌ای (Procedural Audio) برای کارکرد ۱۰۰٪ آفلاین حتی بدون فایل صوتی
   - امواج مغزی باینورال تتا و آلفا با تفکیک فرکانسی گوش چپ و راست
   - تایمر خواب هوشمند با محو شدن تدریجی (Fade-out)
   - ذخیره ترکیب‌های صوتی با نام دلخواه و میکس‌های آماده بالینی

۴. **مدیتیشن باکلام و بی‌کلام:**
   - پروتکل MBSR، اسکن بدن، مهربانی (Metta)، خواب آرام، اضطراب و تمرکز کاری
   - حالت متن (زیرنویس زمان‌بندی‌شده آرام) و صفحه «متن برای گوینده» با امکان کپی
   - کاسه تبتی برای جلسات آزاد و سکوت

۵. **کتابخانه و مقالات علمی:**
   - قفسه کتاب به سبک طاقچه (در حال مطالعه، نشان‌شده‌ها، تمام‌شده‌ها)
   - کتاب‌خوان اختصاصی با تم‌های کاغذ (سفید، کاغذی/سپیا، تیره)، تغییر اندازه فونت و فهرست فصول
   - ۱۰ مقاله علمی داوری‌شده با ذکر منابع DOI و پادکست‌های رادیو آرامیتو

۶. **نوتیفیکیشن و یادآورها:**
   - بانک ۶۰+ حکمت و جمله آرامش‌بخش روزانه
   - یادآور زمان خواب، بیداری، مدیتیشن و تنفس با قابلیت ارسال تست

## ساختار پوشه‌ها
```
├── android/                         # پروژه نیتیو اندروید (پس از cap add)
├── public/
│   ├── audio/                      # محل قرار دادن فایل‌های صوتی اختیاری ({id}.mp3)
│   └── fonts/                      # فونت محلی Vazirmatn (woff2 / ttf)
├── scripts/
│   └── patch-android.mjs           # اسکریپت اعمال خودکار مجوزهای اندروید
├── src/
│   ├── components/                 # کامپوننت‌های شیشه‌ای، هدر، تب‌بار، پلیر و اونبوردینگ
│   ├── data/                       # اطلاعات تنفس، صداها، کتاب‌ها، مقالات و منابع علمی
│   ├── features/                   # ماژول‌های مجزا (home, breathe, sounds, library, ...)
│   ├── services/                   # موتور صوتی AudioEngine، Storage و نوتیفیکیشن‌ها
│   └── utils/                      # تاریخ شمسی، اعداد فارسی و قالب‌بندی
├── capacitor.config.ts             # تنظیمات خروجی Capacitor اندروید
└── .github/workflows/android.yml    # پایپ‌لاین بیلد خودکار APK با GitHub Actions
```

## افزودن فایل‌های صوتی و فونت محلی

### ۱) فونت وزیر (Vazirmatn):
فایل‌های فونت را در مسیر `public/fonts/` قرار دهید:
- `Vazirmatn[wght].woff2` یا نسخه‌های `Vazirmatn-Regular.woff2`, `Vazirmatn-Bold.woff2`

### ۲) فایل‌های صوتی باکیفیت استودیویی:
اپلیکیشن در غیاب فایل‌ها با تولید رویه‌ای Web Audio کار می‌کند. برای افزودن صداهای واقعی ضبط‌شده، فایل‌های زیر را در `public/audio/` با فرمت mp3 بگذارید:
- `rain.mp3`, `thunder.mp3`, `waves.mp3`, `river.mp3`, `wind.mp3`, `fire.mp3`, `forest.mp3`, `birds.mp3`, `crickets.mp3`, `cafe.mp3`

## گرفتن خروجی APK اندروید

### روش اول: بیلد با GitHub Actions (بدون نیاز به نصب اندروید استودیو)
مراحل کامل ساخت مخزن جدید در بخش «انتشار روی مخزن جدید» پایین همین فایل آمده است.
فایل `.github/workflows/android.yml` آماده است. کافی است کد را به مخزن گیت‌هاب پوش کنید؛ اکشن به صورت خودکار پروژه را بیلد کرده و فایل `Aramito-debug-apk` را در تب Artifacts قرار می‌دهد.

### روش دوم: اجرا در سیستم خودتان با Android Studio
```bash
# ۱) نصب وابستگی‌ها
npm install

# ۲) بیلد وب‌اپلیکیشن
npm run build

# ۳) افزودن و پچ کردن پلتفرم اندروید
npm run android:add
node scripts/patch-android.mjs
npm run android:sync

# ۴) باز کردن در اندروید استودیو جهت خروجی APK
npm run android:open
```

سپس در Android Studio از منوی `Build > Build Bundle(s) / APK(s) > Build APK(s)` فایل APK آماده نصب را دریافت کنید.

## انتشار روی مخزن جدید گیت‌هاب و گرفتن APK

۱. در حساب جدید گیت‌هاب یک مخزن خالی بسازید (بدون README و بدون .gitignore).

۲. در پوشهٔ پروژه:
```bash
git init -b main
git add .
git commit -m "Aramito first commit"
git remote add origin https://github.com/<USERNAME>/<REPO>.git
git push -u origin main
```

۳. بعد از push، در تب Actions مخزن، اجرای «Build Android APK (Aramito)» شروع می‌شود (حدود ۵ تا ۱۰ دقیقه).

۴. پایان اجرا، فایل `Aramito-debug-apk` را از بخش Artifacts دانلود کنید. فایل `app-debug.apk` داخل آن است.

نکته: پوشهٔ `android/` ساخته نمی‌شود و در مخزن نیست؛ هر بار توسط خود workflow تولید می‌شود. هیچ secret یا توکنی لازم نیست.
